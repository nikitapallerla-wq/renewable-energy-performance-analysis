# Power BI Dashboard

This folder contains the Power BI report for the Renewable Energy Performance Analysis project.

## Dashboard Pages

1. **Renewable Energy Performance Overview**
   - Energy generation and export
   - Billing and outstanding collections
   - Monthly energy trends

2. **Plant Performance & Loss Analysis**
   - Plant-wise generation and export
   - Capacity Utilization Factor (CUF)
   - Transmission loss and RKVAH loss analysis

3. **Billing & Receivables Analysis**
   - Invoice amounts and receivables
   - Collection performance
   - Outstanding collections

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data modelling

## Project File

`Renewable_Energy_Analytics.pbix`

## Data Quality Note

Some plants contain negative transmission-loss values and export-efficiency values above 100%. These require validation before drawing operational conclusions.
